<pre><span style="font-size: 14pt;"><strong>Input: </strong>root = [1, 2, 3]<strong><br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/930109/Web/Other/blobid2_1782205717.png" height="100"> </strong><strong>
